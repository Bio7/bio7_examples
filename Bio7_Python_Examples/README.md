# Python examples

| Folder | Contents |
|---|---|
| [Bio7_API](Bio7_API) | The Python API of Bio7 (the embedded Python): plots, image processing and analysis, R, ImageJ macros and the Java API, progress and jobs, classes, 3D plots |
| [Simulation](Simulation) | Simulations (the simulation API for Python): grids, agents, 3D scenes, networks, experiments |
| [OpenCV](OpenCV) | OpenCV: video, the camera, motion tracking, template matching (also used by Java GUIs of Bio7_Java_Examples) |
| [Markdown](Markdown) | Python chunks in the markdown editor |

The folder `data` contains the images, 3D models and geodata of the simulations.
