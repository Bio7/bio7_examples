# 3D models of the simulation examples

## Sheep and wolf (glTF 2.0)

Low-poly models made for the simulation examples of Bio7 (generated by a script, CC0: free to use without attribution).
The animations are `walk`, `run` and `graze` (sheep) or `idle` (wolf). In the simulation API:

```java
loadModel("sheep", "data/models/sheep.glb");
agent.model = "sheep";
agent.animation = "walk";
```

Other glTF models (.glb, .gltf, also skinned and animated) can be used in the same way, e.g., the samples of the Khronos Group
(github.com/KhronosGroup/glTF-Sample-Assets). Keep the license of a model (e.g., CC BY: the attribution) when you publish an exported page.

## A small town (OBJ and STL)

`house.obj` (with `house.mtl` and the roof texture `roof_tiles.png`), `tree.obj` (with `tree.mtl`) and the church tower
`tower.stl` (binary STL), made for the example `glider_town` (generated by a script, CC0). OBJ files are read with y up
(their materials: the color `Kd`, the transparency `d` and the texture `map_Kd`), STL files with z up (one color). The HTML
export converts them to glTF:

```python
self.load_model("house", "data/models/house.obj")
self.place_model("house", x, y, heading=90, size=120)   # size: the height
```
