Python Chunks in the Bio7 Markdown Editor

Python chunks

A chunk which starts with ```{python} runs in the embedded Python of Bio7 (the same Python as the console, the Python-Shell and the scripts). Run a chunk with the ▶ button in the bar above the chunk, all chunks above with ▶▶ (Run Above), or all chunks of the document with Run All. The output is shown below the chunk. Python is started automatically if it is not running.

The variables are created in the workspace of Python (__main__): they are available in the following chunks, the console and the Python-Shell view.

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
x = np.linspace(0, 10, 50)
y = 2.5 * x + rng.normal(0, 2, x.size)
print("Created", x.size, "values")
## Created 50 values

The value of the last expression is printed

A linear model with numpy

slope, intercept = np.polyfit(x, y, 1)
residuals = y - (slope * x + intercept)
r2 = 1 - residuals.var() / y.var()
f"y = {slope:.2f} * x + {intercept:.2f}   (R² = {r2:.3f})"
## 'y = 2.59 * x + -0.27   (R² = 0.963)'

Plots

A matplotlib figure of a chunk is shown below the chunk (in the size of the plots of the editor, unless a figsize is given).

import matplotlib.pyplot as plt

plt.scatter(x, y, s=18, alpha=0.7, label="data")
plt.plot(x, slope * x + intercept, color="crimson", label="fit")
plt.xlabel("x")
plt.ylabel("y")
plt.legend()
plt.title("Linear regression")
plt.show()

Several figures (or subplots) of one chunk are shown one below the other:

Errors

The error is shown below the chunk and stops Run All. When the document is rendered (knitr), an error stops the rendering unless the chunk has the option error=TRUE (as this one). If a variable is used which is created in a chunk above that was not run yet (e.g., x after a restart of Bio7), the hint to run the chunks above (▶▶) is shown.
